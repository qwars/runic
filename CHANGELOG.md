# Changelog

Все заметные изменения в этом проекте будут документироваться в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и этот проект придерживается [Semantic Versioning](https://semver.org/lang/ru/).

## [1.3.0] - 2026-10-09

### 🛡️ Исправлено (Fixed)
- Устранены все предупреждения `cargo clippy -- -D warnings` (включая замену `sort_by` на идиоматичный `sort_by_key` с `Reverse`).
- Улучшена обработка ошибок: все сообщения об ошибках и отладочная информация теперь используют строгую типизацию и безопасные методы.

### ✨ Добавлено (Added)
- **Профилирование ресурсов**: Добавлен сбор метрик использования памяти (VmRSS) и времени CPU (`getrusage`) для каждого IPC-запроса.
- **Трекинг потоков (`ThreadTracker`)**: Внедрен механизм мониторинга активных и завершенных фоновых потоков. Позволяет отслеживать пиковое потребление памяти, время жизни потока и количество выполненных задач, предотвращая незаметное исчерпание ресурсов.
- **Цветной вывод в консоль**: Добавлена поддержка ANSI-цветов для четкого визуального разделения типов сообщений:
  - 🔴 Красный: Ошибки и STDERR дочерних процессов.
  - 🟡 Желтый: Предупреждения и ошибки инициализации.
  - 🟢 Зеленый: Успешный запуск процессов.
  - 🔵 Голубой: Отладочная информация (Debug).
  - 🟣 Пурпурный: Данные профилирования производительности.
- **Расширенный набор тестов**: Добавлено 15 комплексных модульных тестов, покрывающих все IPC-действия (`read`, `write`, `exec`, `stream`, `watch`, `unwatch`), а также граничные случаи (пустые target, дубликаты, очистка ресурсов).
- **Полная локализация**: Все внутренние логи, сообщения об ошибках и отладочный вывод переведены на чистый, современный русский язык без англицизмов.

### ⚙️ Изменено (Changed)
- Периодический вывод статистики потоков в режиме отладки (каждые 30 секунд) для удобного мониторинга состояния приложения в реальном времени.
- Улучшена читаемость кода за счет введения констант для ANSI-цветов и интервалов таймеров.

## [1.2.0] - 2026-10-08

### 🛡️ Исправлено (Fixed)
- **Критическое**: Устранено состояние гонки TOCTOU (Time-of-Check to Time-of-Use) в действии `stream`. Проверка наличия запущенного процесса и его регистрация теперь выполняются атомарно под одним блокировщиком мьютекса.
- **Критическое**: Устранена паника (`unwrap()`) в действии `watch` при мониторинге директорий, если параллельно вызывался `unwatch`. Заменено на безопасный `insert`.
- **Критическое**: Устранена двойная отправка `SIGKILL` и вызов `waitpid` для одних и тех же PID в функции `kill_and_clear_tracked`. Теперь PID, уже обработанные через `running_streams`, исключаются из списка `spawned_pids` перед массовой очисткой.
- Заменены все небезопасные вызовы `.unwrap()` на `.lock()` мьютексов на использование функции `safe_lock`, что предотвращает панику приложения при отравлении (poisoning) мьютекса, особенно в обработчиках сигналов завершения (SIGTERM/SIGINT).

### ✨ Добавлено (Added)
- Механизм корректного завершения (graceful shutdown) фоновых потоков (`watch` и детектор сна системы) с использованием флага `AtomicBool`. Потоки теперь чисто останавливаются при закрытии приложения, а не остаются висеть в фоне.
- Логирование ошибок выполнения JavaScript (`run_javascript`) в режиме отладки (`--debug`).
- Новые модульные тесты для проверки исправленных уязвимостей:
  - `test_handle_action_stream_duplicate_error` (проверка блокировки повторного запуска stream).
  - `test_kill_and_clear_tracked_no_double_kill` (проверка отсутствия двойного убийства процессов).
  - `test_shutdown_flag_stops_watch_loop` (проверка остановки потока watch при shutdown).

### ⚙️ Изменено (Changed)
- Улучшена совместимость с более старыми версиями компилятора Rust (MSRV < 1.87): цепочки `let` (let chains) заменены на вложенные конструкции `if let`.
- Устранено предупреждение Clippy `lines_filter_map_ok`: использование `.flatten()` на итераторе `io::Lines` заменено на `.map_while(Result::ok)` для предотвращения потенциальных бесконечных циклов при ошибках чтения.
- Удалены случайные замыкающие пробелы в описаниях аргументов командной строки (`clap`).
