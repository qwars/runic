# Changelog

Все значимые изменения в этом проекте документируются в этом файле.

## [1.0.0] - 2026-10-08  

### 🚀 Добавлено
- **Hot-reload (Watch mode):** Полноценная поддержка автоматической перезагрузки виджетов при изменении исходных файлов или конфигурации. Идеально для разработки и быстрой настройки.
- **Мониторинг логов:** Добавлена система отслеживания и передачи логов для упрощенной отладки виджетов.
- **Улучшенная работа с экранами (Screen):** Доработана логика определения параметров экрана для корректного позиционирования виджетов.

### ⚡ Улучшено
- **Многопоточность:** Логика мониторинга файлов и обработки событий вынесена в отдельные потоки, что гарантирует отсутствие блокировок основного UI-цикла и высокую отзывчивость интерфейса.
- **Надежность Watch:** Улучшена обработка ошибок и стабильность работы системы отслеживания файлов.

### 🛠️ Техническое (Chore)
- Обновлены GitHub Actions до версий, поддерживающих Node.js 24, для обеспечения безопасности и актуальности CI/CD пайплайна.
